# QA reports

QA reports for v2.6.0 and later releases and pull requests; older QA reports live in git history.

Reports written before the branch switch (2026-10-29) use `main` for the 2.x app, now kept as the branch `old`, and
`feature/ci4` for the CodeIgniter 4 app, which `main` carries since the switch. The reports themselves are not
rewritten.
