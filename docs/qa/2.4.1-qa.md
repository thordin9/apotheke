# QA: Apotheke 2.4.1 (follow-ups from the 2.4.0 QA pass)

PR #26 (`cursor/autofill-2-4-1-followups-720d`, head `6891291`; base `main` at the v2.4.0 merge `23a0737`). QA run on 2026-10-19 (EEST),
against the autofill stub (`php -S 127.0.0.1:8090 tests/stubs/autofill-stub.php`, reused from the 2.4.0 harness, plus a second stub on `:8091` with `STUB_MAX_BYTES=2097152` for the alternate oversize case) only. No real service or Jetson was used. Every scenario ran on a fresh, empty `DATA_DIR`. Never touched the live `/workspace/apotheke` data.

Fixes under test (from `docs/qa/2.4.0-qa.md`):

- **L1.** Analyze stays focusable with `aria-disabled` / `aria-busy`; focus is restored if it fell to `body`.
- **L2.** *Test with a photo* gets the same single 503 retry as the item form (retry once only when `Retry-After` ≤ the admin timeout).
- **Oversize message.** Status line states the limit (`max N MiB / N bytes`); no new browser-side size check (L3 waits for v2.5).
- **L5.** Admin guide and `autofill.md` reworded so `loaded` is not read as "fast".
